Data Structures Used

1. Queue

Regular customers are served using the FIFO (First In, First Out) principle.

2. Priority Queue

Priority customers are moved ahead of regular customers and are served first.

3. Linked List

Each customer is stored inside a linked-list node. Every node contains customer information and a reference to the next customer.
